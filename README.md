# Startuppy

Browse early-stage companies across **Y Combinator**, **Techstars**, **Entrepreneur First**, **Antler**, and **a16z Speedrun** — a problem/solution map for founders.

Static vanilla SPA (Companies + Jobs). Live: see Vercel project linked to this repo.

| Techstars | Recent cohorts (2023+) |
| Entrepreneur First | Full public portfolio mirror |
| Antler | Full public portfolio mirror |
| a16z Speedrun | All public Speedrun cohorts |

Filter by **Source**, YC **Batch**, industry, tags, rebrand, and watchlist. Export/import watchlist JSON for cross-device use.
